# 校园足球联赛 V0.2 · 本地重制版

这是一份根据原对话需求重新制作的静态网站，并非原 ZIP 的恢复副本。
制作日期：2026-11-06。所有球队、球员、赛程、比分和事件均为虚构演示数据，非学校官方网站。

## 打开网站

解压完整文件夹，双击 `index.html`，使用 Edge、Chrome 或其他现代浏览器打开。
无需安装依赖、无需服务器、无需登录、无需联网。不要将 index.html 单独移出文件夹。

## 项目结构

```text
Campus-Football-League-V0.2/
├── index.html    网页入口
├── styles.css    白蓝色响应式样式
├── app.js        演示数据、页面交互与榜单计算
└── README.md     本说明
```

## 页面与功能

- 首页：赛季概览、下轮比赛、最新赛果、射手榜、积分榜摘要。
- 赛程：9 支球队单循环，共 9 轮 36 场，每支球队 8 场、轮空 1 轮。前 4 轮为已结束演示比赛。
- 支持按轮次、球队、状态筛选比赛，点击查看进球、助攻、红黄牌事件。
- 积分榜：从比分自动计算胜平负、进失球和积分；胜 3 分，平 1 分，负 0 分。
- 同分依次比较净胜球、进球数、球队编号；仅为演示排名规则。
- 球队：9 支演示球队，每队 9 位球员，点击查看阵容和球员数据。
- 球员榜单：射手榜、助攻榜、黄牌榜、红牌榜，可搜索球员或球队；同项数据相同显示并列名次。
- 全站适配手机、平板和电脑；弹窗支持关闭按钮与 Esc 键。

## 数据说明与后续修改

`app.js` 中的 `teams` 与 `players` 定义球队和球员，`matches` 通过固定种子生成示例比赛。
比分和事件保持对应，积分与球员榜单均从同一份比赛记录统计。刷新不会改变演示数据。
“下轮”是演示赛程中第一场未完成的比赛，不跟随系统日期变化。

本版本为只读演示，没有后台、数据库、真实数据录入或多人同步。
如需正式运营，后续应接入真实比赛数据与管理系统，并由赛事组织方确认积分和纪律规则。
